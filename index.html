03 / BACKGROUND

배경 보관함 · AI 생성

첫 칸은 사진 색상으로 자동 만든 배경, 나머지는 AI로 만든 배경입니다. 한 번 만든 AI 배경은 이 기기에 저장되어 다른 사진·다른 스타일에서도 다시 쓸 수 있습니다(재과금 없음).
선불 충전 API · 생성 버튼을 누를 때만 과금
사진 맞춤을 위해 사진 축소본(최대 4장)을 이미지 분석 AI에 전송해 색감·장소·분위기를 파악하고(같은 사진 구성은 결과를 재사용해 다시 과금되지 않음), 추출한 색상 코드와 함께 배경 생성에 반영합니다. 사진은 생성 이미지에 재현하지 않고, 포스터에는 브라우저에서 원본 사진을 직접 합성합니다. 요금은 ‘후보 장수 × 품질’만큼 발생합니다. 공식 안내
메인 사진 맞춤 AI 배경: ★ 대표 사진은 그대로 걸리고, 그 뒤에 같은 장소를 더 넓게 본 듯한 풍경이 사진의 색감·계절·빛에 맞춰 새로 그려집니다. ★ 사진 1장(1024px 이하로 줄인 사본)을 OpenAI에 보내 참고로 쓰며, 사람은 그리지 않도록 지시합니다. 풍경 중심 사진을 ★로 지정하길 추천해요. 요금 없이 쓰려면 보관함의 ‘메인 사진 색감 (무료)’을 고르세요.
사진을 선택하면 포스터가 바로 만들어집니다. AI 배경 없이도 사진 색상으로 배경이 자동 구성됩니다.
